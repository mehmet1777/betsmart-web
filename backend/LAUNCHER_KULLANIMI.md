# 🚀 BETSMART LAUNCHER KULLANIMI

## ✨ Yeni Özellik: Modern Launcher!

Artık BetSmart'ı şık bir launcher ile başlatabilirsiniz!

---

## 🎯 LAUNCHER İLE BAŞLATMA:

### **Yöntem 1: Python ile**
```bash
python launcher.py
```

### **Yöntem 2: Çift tıklama**
```
launcher.py dosyasına çift tıklayın
(Python yüklüyse otomatik açılır)
```

### **Yöntem 3: Başlangıçta otomatik**
Windows başlangıcına ekleyin:
1. Win + R → `shell:startup`
2. launcher.py kısayolunu buraya atın

---

## 🎨 LAUNCHER ÖZELLİKLERİ:

- ✅ **Modern gradient arkaplan** (mor-mavi-turkuaz)
- ✅ **Şık tasarım** (resimdeki gibi)
- ✅ **Tek tıkla başlatma**
- ✅ **Minimize/Kapat butonları**
- ✅ **Sürükle-bırak ile taşıma**
- ✅ **Durum bildirimleri**

## 📱 KULLANICI AKİŞİ:

```
1. launcher.py çalıştır
   ↓
2. 🚀 Logo ve "BetSmart" başlığı görünür
   ↓
3. "▶ BAŞLAT" butonuna tıkla
   ↓
4. Ana uygulama açılır
   ↓
5. Launcher kapanır
```

---

## 🔧 EXE YAPMA (Opsiyonel):

Launcher'ı exe olarak derlemek için:

```bash
# PyInstaller kur
pip install pyinstaller

# Launcher'ı derle
pyinstaller --onefile --windowed --icon=icon.ico launcher.py

# Sonuç: dist/launcher.exe
```
